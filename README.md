# SAN SMP — site complet

## Mise en ligne
1. Installe Node.js.
2. Ouvre un terminal dans ce dossier.
3. Lance `npm install`.
4. Lance `npm start`.
5. Ouvre `http://localhost:3000`.

Pour mettre le site en ligne, utilise un hébergeur Node.js (Render, Railway, VPS, etc.).
Les demandes sont enregistrées dans `data/site-data.json`.

Important : le site collecte des demandes, mais ne démarre pas automatiquement Aternos.
Ne demande jamais de mot de passe Aternos aux joueurs.
